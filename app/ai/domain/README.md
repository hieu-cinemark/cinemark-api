# app/ai/domain

Tri thức nghiệp vụ dùng trong prompt và hậu xử lý, không gọi AI.

- `aspects.py`: bộ khía cạnh và giai đoạn khán giả cố định (chỉ thêm key, không đổi tên key cũ).
- `movie_context.py`: khối thông tin phim chèn vào prompt.
- `cinema_visit.py`: luật nhận diện câu nói về việc đi rạp.
- `accuracy.py`: đo độ chính xác nhãn máy so với nhãn người.
